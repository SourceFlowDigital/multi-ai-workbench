## 一、产品定义

**一句话定义：**
为用AI运转一人制公司的创业者，提供一个极简的多AI角色协同平台，在同一界面内调度多个AI并行工作，一键配置即可上手，无需搭建流程。

**产品使命：**
把AI推广给更多普通人用，降低AI使用门槛——这是比"解决自己痛点"更底层的驱动力。

**目标用户：**
- 有明确创业方向的一人制创业者
- 已在使用AI工具辅助工作（非小白）
- 无技术团队，靠自己+AI运转
- 以电脑端工作为主

**核心使用场景：**
遇到棘手问题时，由多个AI并行研究，Claude做最终判断和方向决策。发挥各AI长处——Claude逻辑强、DeepSeek懂国内语境更符合国内使用习惯、GPT知识面广。这是产品最核心的价值点。

**差异化定位：**
现有产品（Coze、Dify、Taskade等）的逻辑都是"搭工作流"，本产品的逻辑是"模拟公司组织架构、指挥团队"——交互模型本质不同。极简上手、一键配置，是核心差异化。

## 二、竞品结论

| 产品 | 定位 | 与本产品的关系 |
|------|------|------|
| Coze/扣子 | 零代码Agent搭建平台 | 用户需自己学搭建，非直接竞品 |
| Paperclip | 开源AI公司操作系统 | 最接近的技术形态，但是开源框架非产品，用户仍需自己搭 |
| Taskade | AI团队+项目空间 | 偏生产力工具，非角色协作 |
| Sintra | AI员工市场 | 角色包装为"员工"，执行闭环深度有限 |

**核心结论：** 市场上缺乏面向非技术一人创业者的"AI角色协作+任务管理"一体化开箱即用产品，市场空白真实存在，但赛道已开始升温（扣子3.0、Paperclip GitHub暴涨）。

## 四、产品形态：两步走

### 第一步：自用网页版（验证阶段）
- 无用户注册系统，无数据库
- API Key和数据全部存储在浏览器本地
- 服务器仅托管静态页面，零额外压力
- 目的：自己用顺手，积累优化经验

### 第二步：桌面端买断制（商业化阶段）
- 封装为桌面应用，本地运行
- 复用源流WPS智能助手的成熟买断制路径
- 解决网页版的注册、数据存储、服务器占用问题

## 五、MVP功能清单

**做：**
1. 预设角色库（执行经理 + 5-8个职能角色）
2. API Key配置页（支持多AI平台）
3. 总经理下达任务入口
4. 执行经理自动分发逻辑
5. 各角色并行独立响应面板
6. 执行经理汇总输出（简明扼要汇报，不做最终决策）

**不做（自用阶段，留作v2.0）：**
1. 角色自定义设置器——让用户在AI协助下自定义角色
2. 角色互相讨论（真正多轮讨论，非轮询）——技术复杂度高，且轮询实现对产品价值提升有限
3. 用户注册/登录系统
4. 数据云端存储

## 九、毒舌审查结论（project-review）

**立项建议：谨慎立项**

**致命问题：**
1. 用户验证为零，付费意愿完全未知
2. ¥99买断需卖出100+用户才回本开发时间成本，获客路径不清晰
3. 经济通、政策通、688号文工具均待商业化推进，注意力是最稀缺资源，不应被稀释

**高风险点：**
1. 技术复杂度被低估——从"能跑"到"好用"的距离可能是数周到数月
2. 竞品赛道正在加速（Paperclip、扣子3.0），窗口期有限
3. 用户自持API Key对目标用户（不爱折腾的普通人）是认知门槛，与产品定位存在张力，商业化前需解决

**最小验证路径：**
用Claude Artifacts做3天可交互原型，模拟多角色并行响应一个真实任务，自用一周验证交互模式是否真正省力，验证通过再投入正式开发。
